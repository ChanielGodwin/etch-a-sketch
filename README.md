# Etch-a-Sketch

This project is a browser based sketchpad built as part of **The Odin Project Foundations** course. The project uses JavaScript and DOM manipulation to dynamically create and resize a "grid" within a fixed sketch area (960px).

## Features

* Generate a customizable grid from **1×1 up to 100×100** using a `prompt`.
* Replace the existing grid with a new grid while maintaining the same total sketchpad size.
* Change a square's color to a randomly generated RGB color when the mouse passes over it.
* Progressively darken each square by increasing its opacity with each interaction.
* Clean the sketchpad and regenerate the current grid.
* Dynamically create and modify HTML elements using JavaScript.

## Skills Practiced

* JavaScript DOM manipulation
* Creating and modifying HTML elements
* Event listeners and mouse events
* Functions and variables
* Loops
* User input with `prompt()`
* Random number generation
* CSS manipulation with JavaScript
